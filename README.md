# Triflex-Pipeline-Stress-Analysis

> Pipeline stress analysis project using TRIFLEX software, completed during an internship at Chart Industries.

---

## Overview

This repository documents a **pipe stress analysis** project conducted at **Chart Industries** using TRIFLEX — a specialized pipe stress analysis software used in pressure vessel and piping engineering. The analysis evaluates mechanical stress, displacement, and load distribution in cryogenic piping systems to ensure compliance with ASME piping codes (B31.3 / B31.1).

        ## Project Details

        ### Calculation Conditions
        Documents the input parameters for the TRIFLEX analysis:
        - Pipe material properties and operating conditions (pressure, temperature)
        - Pipe geometry: nominal size, wall thickness, insulation type
        - Support locations, restraint types, and boundary conditions
        - Design code and allowable stress criteria

        ### Pipe Modeling
        Shows the 3D model of the piping system in TRIFLEX:
        - Pipe routing and isometric layout
        - Node numbering for stress point identification
        - Anchor and guide restraint locations
        - Expansion loops and flexible connections

        ---

        ## What is Pipe Stress Analysis?

        Pipe stress analysis verifies that piping systems can safely withstand:
        - **Sustained loads** — Weight of pipe, fluid, and insulation
        - **Thermal expansion** — Pipes expand/contract with temperature changes
        - **Occasional loads** — Wind, seismic, and pressure surges
        - **Displacement loads** — Movements from connected equipment
